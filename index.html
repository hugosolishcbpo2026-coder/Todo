Built for a real city launch

An operational MVP — not a demo. Durable data, live tracking, real billing.

🚕

Driver-first economics

Drivers keep 100% of fares. A flat 100 MXN/day membership (discounted monthly) replaces commission. Expired memberships block dispatch.

⚡

Realtime dispatch

Socket.IO pushes ride offers to nearby online drivers and streams live status to riders and the ops dashboard.

💬

WhatsApp-native

OTP login and ride notifications over the WhatsApp Business Cloud API, with a mock fallback for local development.

💳

Stripe subscriptions

Tiered plans with Checkout, Customer Portal, and signature-verified, replay-protected webhooks. State is always server-authoritative.

🗄️

Durable local data

SQLite is the source of truth — rides, earnings, memberships and payments survive restarts. Backups/exports go to your Google account.

🔒

Secure by default

JWT auth with role guards, validated DTOs, and verified webhooks. No secrets in the repo; everything via environment.

Architecture

A pnpm/TypeScript monorepo. Local-first runtime, GitHub for source.

  • apps/api — NestJS API: auth, riders, drivers, rides, dispatch, payments, membership, realtime gateway, WhatsApp, webhooks
  • apps/admin — Next.js operations dashboard (live)
  • apps/rider · apps/driver — React Native (Expo)
  • packages/shared — typed API client + domain contracts
  • SQLite source of truth · Socket.IO realtime · Stripe billing

Run it locally

No Docker required. No cloud required.

corepack pnpm@9.12.3 install
corepack pnpm@9.12.3 build

# seed demo data + start the API and admin
corepack pnpm@9.12.3 --filter @todo/api db:seed
corepack pnpm@9.12.3 dev

# API   http://localhost:4000  (Swagger at /docs)
# Admin http://localhost:3000
